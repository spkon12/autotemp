# Optional Dev Container

This Dev Container provides ESP-IDF inside Docker for VS Code/Cursor development.

- **Not used on the TP520** in normal deployment
- **Not required** if ESP-IDF is installed locally on your laptop
- Pulling the ESP-IDF image is large (~15 GB) — only use when you want containerised builds

For the standard workflow, install ESP-IDF on your laptop and follow [docs/firmware-build.md](../docs/firmware-build.md).
